Local privacy policy / Локальная политика конфиденциальности

Version 2026-07-29. This policy describes the free personal, local-first build. It has no hosted service, advertising, analytics, telemetry, or developer-operated database.

Data and purpose

The app stores a local profile, encrypted provider credentials when optional OAuth is enabled, playlist snapshots, exact provider IDs, matching/review decisions, write receipts, and a retry journal. It uses them only to import playlists, let the operator choose exact targets, perform explicitly approved playlist changes, resume safely, and produce an honest local report. Provider passwords are never requested.

Storage, sharing, and retention

Data stays in SQLite and the encrypted vault on this computer. Requests go only to the provider endpoint selected by the operator. No data is sold or shared with another backend. Raw playlist/track detail is retained for the active transfer and a default support window of 24 hours; YouTube API metadata is deleted or refreshed within 30 days. Summary counts may remain in local history until the operator clears it.

Control, revocation, and deletion

Connections can be disconnected and all local data can be deleted in Settings. YouTube disconnect first calls Google's revocation endpoint and deletes related local API Data. If that call is unavailable, revoke access in Google Security permissions, then use the explicit manual-revocation confirmation. You may also review Google's Privacy Policy. Deletion does not remove playlists already created at a provider.

Provider terms and attribution

Optional YouTube API use is subject to the YouTube Terms of Service and YouTube API Developer Policies. Spotify-linked data is identified as Spotify-supplied and links back to Spotify; use is subject to the Spotify Developer Terms and Developer Policy.

Security and contact

OAuth tokens are AES-256-GCM encrypted at rest; the vault key exists only while the local profile is unlocked. The MV3 extension receives no OAuth token or app cookie. This is a self-operated personal installation: its operator is the data controller and the contact shown on the operator's OAuth consent screen/source distribution is the privacy contact. The optional API flags are fail-closed until that operator has supplied a valid contact and accepted current provider policies.

Русское резюме: данные остаются на компьютере, телеметрии и облачного backend нет; доступ Google можно отозвать, а локальные данные — полностью удалить. Опциональные provider endpoints выключены до явного принятия актуальных правил оператором локальной установки.
