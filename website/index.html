НОРМАЛЬНЫЙ СЦЕНАРИЙ

Аккаунт или официальный экспорт — не ручная таблица.

Прямой account-доступ используется только там, где официальный бесплатный API действительно это позволяет. В остальных случаях Playlist-Transfer открывает официальный export-портал и локально читает скачанный архив.

  1. 01
    Получите библиотеку

    Войдите через Google либо скачайте официальный ZIP Spotify/Google Takeout.

  2. 02
    Выберите плейлисты

    Один архив может содержать сотни списков; порядок и повторы сохраняются.

  3. 03
    Запустите перенос

    Выберите destination и точность. Непроверенные действия никогда не становятся «успехом» автоматически.

ЧЕСТНЫЕ ВОЗМОЖНОСТИ

Что доступно в бесплатной версии

YTDIRECT API

YouTube / Music

Owned-плейлисты через официальный Google OAuth. Альтернатива — ZIP Google Takeout с playlist CSV.

SPOFFICIAL EXPORT

Spotify

Официальный Account Data ZIP с Playlist JSON читается целиком. Premium и developer app не обязательны.

SCEXTERNAL GATE

SoundCloud

Неподтверждённые API/export-возможности не маскируются. Runtime останавливается до mutation при внешнем gate.

НЕ SaaS

Публичен сайт. Ваши данные — нет.

Vercel-страница содержит описание и ссылки на релиз. Рабочее приложение запускается на 127.0.0.1, использует локальную SQLite и зашифрованный vault. Плейлисты и credentials не отправляются на этот сайт.
